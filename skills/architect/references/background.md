# Background and examples

Escalating without ever downgrading is how scarce quota leaks into mechanical work.

A one-line fix you make yourself costs the user their visibility, skips the
guardrails you impose on workers, and is how a branch ends up with an agent and you pushing to it.

A hidden subagent gives them none of that.

```
filter bar            ← the initiative's workspace
  - architect         ← you
  - worker foo        ← its own herdr worktree
  - worker bar        ← its own herdr worktree
```

A stale name makes a working pane impossible for the user to find.

Several architects and their workers share one machine. Running out of open file handles has crashed it more than once. 

The user set the rule that an architect obeys the Coordinator themselves ("It must obey the coordinator … That's the whole point").

A quiet pass is how a regression ships.
